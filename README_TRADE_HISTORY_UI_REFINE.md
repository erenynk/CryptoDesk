# İşlem Geçmişi UI küçük düzenleme

Değişiklikler:

- `COIN` başlığı `VARLIK` olarak değiştirildi.
- En sola `NO` sütunu eklendi.
- `NO` sütunu 64 px sabit genişliktedir.
- `NO` başlığına tıklamak sıralamayı değiştirmez.
- Başka sütunlara göre sıralama yapıldığında numaralar her zaman
  ekrandaki sıraya göre `1, 2, 3...` olarak yeniden yazılır.
- Alış satırlarında PnL hâlâ tamamen boştur.
- Satış PnL davranışı değiştirilmedi.
- Diğer tablo font, renk, padding ve satır yüksekliği değerleri korunmuştur.
